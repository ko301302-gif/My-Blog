# 단축 평가와 삼항 연산자로 조건문 간결하게 쓰기

`if문`을 쓰기엔 너무 간단한 조건 처리가 있습니다. 값이 없으면 기본값을 쓰거나, 조건에 따라 둘 중 하나를 고르는 경우죠. 이런 상황에서 자바스크립트는 `&&`, `||`, 삼항 연산자(`? :`)로 코드를 훨씬 짧게 쓸 수 있게 해줍니다.

## &&와 ||의 단축 평가

`&&`는 왼쪽이 참이어야 오른쪽을 실행하고, `||`는 왼쪽이 거짓이어야 오른쪽을 실행합니다. 이 성질을 이용하면 조건부 실행을 한 줄로 줄일 수 있습니다.

```js
user && console.log(user.name); // user가 있을 때만 출력
const name = user.name || '손님'; // name이 없으면 '손님' 사용
```

## 삼항 연산자로 값 고르기

조건에 따라 두 값 중 하나를 바로 변수에 담고 싶다면 삼항 연산자가 편합니다.

```js
const message = age >= 18 ? '입장 가능' : '입장 불가';
```

`if/else`로 변수를 나눠 선언하지 않아도 되니 코드가 한결 간결해집니다.

## 주의할 점

`0`, `''`, `null`처럼 falsy한 값을 정상 값으로 쓰는 경우 `||`는 의도치 않게 기본값으로 덮어씁니다. 이럴 땐 `??`(널 병합 연산자)를 쓰는 게 더 안전합니다. 그리고 삼항 연산자를 중첩해서 쓰면 오히려 가독성이 떨어지니, 조건이 복잡해지면 미련 없이 `if/else`로 돌아가는 것도 좋은 선택입니다.
