# 디바운스와 쓰로틀 쉽게 이해하기

검색창에 글자를 입력할 때마다, 혹은 스크롤할 때마다 이벤트가 수십 번씩 발생하는 경우가 있습니다. 이 이벤트마다 API를 호출하거나 무거운 연산을 실행하면 성능에 문제가 생기죠. 이럴 때 쓰는 대표적인 기법이 디바운스(debounce)와 쓰로틀(throttle)입니다.

## 디바운스: 마지막 한 번만 실행

디바운스는 짧은 시간 안에 이벤트가 연속으로 발생하면, 마지막 이벤트로부터 일정 시간이 지난 뒤에 딱 한 번만 함수를 실행하는 방식입니다. 검색어 자동완성이 대표적인 예시입니다.

```js
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```

사용자가 타이핑을 멈추고 300ms가 지나야 실제로 검색 함수가 호출되므로, 타이핑 중에는 불필요한 호출이 계속 취소됩니다.

## 쓰로틀: 일정 간격으로 실행

쓰로틀은 이벤트가 아무리 자주 발생해도 정해진 시간 간격마다 한 번씩만 함수를 실행합니다. 스크롤 위치를 추적하거나 버튼 연타를 막을 때 유용합니다.

```js
function throttle(fn, interval) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= interval) {
      last = now;
      fn(...args);
    }
  };
}
```

## 어떤 걸 언제 쓸까

디바운스는 "입력이 끝난 후 결과가 궁금할 때"(검색어 자동완성, 폼 유효성 검사), 쓰로틀은 "계속 발생하는 이벤트를 일정 주기로 확인하고 싶을 때"(스크롤, 리사이즈, 마우스 이동)에 적합합니다. 둘 다 이벤트 발생 빈도를 줄여 성능을 지키는 목적은 같지만, 실행 시점에 대한 전략이 다르다는 점을 기억하면 헷갈리지 않습니다.
