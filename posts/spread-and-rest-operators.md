# 스프레드 연산자와 나머지 연산자, ...은 언제 다르게 동작할까

자바스크립트에서 점 세 개(`...`)를 보면 처음에는 다 같은 문법처럼 보이지만, 사실 위치에 따라 역할이 완전히 달라집니다. 값을 "펼치는" 스프레드 연산자와, 값을 "모으는" 나머지 연산자입니다. 이름은 비슷해도 하는 일은 반대라서, 차이를 알아두면 헷갈릴 일이 없습니다.

## 스프레드 연산자: 펼치기

배열이나 객체 안의 값을 하나씩 꺼내서 펼쳐줍니다.

```js
const nums = [1, 2, 3];
const more = [...nums, 4, 5];
// [1, 2, 3, 4, 5]

const user = { name: "지민" };
const updated = { ...user, age: 25 };
// { name: "지민", age: 25 }
```

기존 배열이나 객체를 복사하면서 값을 추가하거나 합칠 때 자주 씁니다. 원본을 직접 수정하지 않아서 안전합니다.

## 나머지 연산자: 모으기

함수 매개변수나 구조 분해에서 남은 값들을 하나로 묶어줍니다.

```js
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // 6

const [first, ...rest] = [1, 2, 3, 4];
// first: 1, rest: [2, 3, 4]
```

몇 개의 인자가 들어올지 모를 때, 혹은 앞부분 값만 따로 쓰고 나머지는 통째로 다루고 싶을 때 유용합니다.

## 구분하는 방법

간단하게 기억하는 방법은 위치입니다. 값을 "받는" 자리(배열·객체 리터럴 내부, 함수 호출 인자)에 있으면 스프레드이고, 값을 "선언하는" 자리(함수 매개변수, 구조 분해의 왼쪽)에 있으면 나머지입니다. 같은 기호라도 문맥이 역할을 결정한다는 점만 기억하면 됩니다.
