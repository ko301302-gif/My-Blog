# 동등 연산자(==)와 일치 연산자(===), 무엇이 다를까

자바스크립트를 처음 배우면 `==`와 `===` 중 뭘 써야 할지 헷갈리는 경우가 많습니다. 둘 다 "두 값이 같은가?"를 확인하는 연산자지만, 비교하는 방식이 다릅니다. 이 차이를 모르면 예상치 못한 버그를 만나기 쉽습니다.

## ==는 타입을 바꿔서 비교한다

```js
console.log(1 == '1');   // true
console.log(0 == false); // true
console.log(null == undefined); // true
```

`==`(동등 연산자)는 두 값의 타입이 다르면 먼저 타입을 맞춘 뒤 비교합니다. 이 과정을 '암묵적 형변환'이라고 부르는데, 문자열 `'1'`이 숫자 `1`로 바뀌거나 `false`가 `0`으로 바뀌는 식입니다. 편리해 보이지만, 어떤 규칙으로 변환되는지 외우기 어렵고 직관과 어긋나는 결과가 나올 때가 있습니다.

## ===는 타입까지 그대로 비교한다

```js
console.log(1 === '1');   // false
console.log(0 === false); // false
console.log(1 === 1);     // true
```

`===`(일치 연산자)는 타입 변환 없이 값과 타입이 모두 같아야 `true`를 반환합니다. 그래서 `1`과 `'1'`처럼 타입이 다르면 값이 같아 보여도 `false`가 됩니다. 동작이 예측 가능하기 때문에 실무에서는 대부분 `===`를 기본으로 사용합니다.

## 정리

특별한 이유가 없다면 `==`보다 `===`를 사용하는 것이 안전합니다. 타입 변환 규칙을 신경 쓰지 않아도 되고, 코드를 읽는 사람도 "정확히 같은 값"이라는 의도를 바로 알 수 있기 때문입니다. 부정 비교인 `!=`, `!==`도 같은 원리로 이해하면 됩니다.
