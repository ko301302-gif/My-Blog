# 즉시 실행 함수(IIFE), 정의하자마자 바로 실행하기

함수를 선언만 해두고 나중에 호출하는 게 보통이지만, 자바스크립트에는 정의와 동시에 바로 실행되는 함수도 있습니다. 이런 함수를 IIFE(Immediately Invoked Function Expression), 즉시 실행 함수 표현식이라고 부릅니다.

## 기본 문법

함수를 괄호로 감싸서 표현식으로 만들고, 그 뒤에 바로 호출 괄호 `()`를 붙이면 됩니다.

```js
(function () {
  console.log('바로 실행됩니다');
})();

(() => {
  console.log('화살표 함수로도 가능합니다');
})();
```

함수를 괄호로 한 번 감싸는 이유는, 그냥 `function () {}()`처럼 쓰면 자바스크립트가 이를 함수 선언문으로 해석해서 문법 오류가 나기 때문입니다. 괄호로 감싸면 함수가 "값"으로 취급되는 표현식이 되어 바로 호출할 수 있습니다.

## 왜 쓸까

IIFE의 가장 큰 장점은 독립된 스코프를 만들어준다는 점입니다. 함수 안에서 선언한 변수는 바깥으로 노출되지 않기 때문에, 전역 공간을 오염시키지 않고 코드를 한 번만 실행하고 끝낼 수 있습니다. 라이브러리 코드나 초기화 로직처럼 "한 번만 실행하고 결과만 남기면 되는" 작업에 자주 사용됩니다.

## 요즘은 얼마나 쓸까

ES 모듈이 등장하면서 모듈 자체가 독립된 스코프를 가지게 되어, 스코프 격리만을 위한 IIFE의 필요성은 줄었습니다. 그래도 번들 없이 브라우저에서 바로 스크립트를 실행할 때 변수 충돌을 막는 용도로는 여전히 유용하게 쓰입니다.
