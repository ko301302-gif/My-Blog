# 안녕하세요, 첫 글입니다

이 블로그는 프레임워크 없이 순수 **HTML, CSS, JavaScript**만으로 만들어졌습니다. 마크다운 파일을 작성해서 `posts` 폴더에 넣고, `posts.json`에 목록을 한 줄 추가하면 새 글이 됩니다.

## 만든 이유

- 빌드 도구 없이 브라우저에서 바로 동작하는 사이트를 만들어보고 싶었습니다.
- 글쓰기는 마크다운으로, 나머지는 최대한 단순하게 유지하고 싶었습니다.

## 특징

1. 다크모드 지원 (시스템 설정 자동 감지 + 수동 전환)
2. 모바일 화면에서도 읽기 편한 레이아웃
3. 마크다운 문법을 그대로 지원 (코드블록, 표, 인용문 등)

```js
console.log("환영합니다!");
```

앞으로 이곳에 이런저런 글을 남겨볼 예정입니다.
