# 고차 함수와 콜백 함수, 자바스크립트다운 코드의 시작

자바스크립트에서는 함수도 숫자나 문자열처럼 값으로 다룰 수 있습니다. 변수에 담을 수도 있고, 다른 함수의 인자로 넘길 수도 있죠. 이 특성 덕분에 등장하는 개념이 콜백 함수와 고차 함수입니다. 처음엔 낯설어 보이지만, 원리를 알면 자바스크립트 코드가 훨씬 자연스럽게 읽힙니다.

## 콜백 함수란

콜백 함수는 다른 함수에 인자로 전달되어, 특정 시점에 대신 호출되는 함수입니다. 예를 들어 버튼 클릭 이벤트를 처리할 때를 생각해 봅시다.

```js
button.addEventListener("click", () => {
  console.log("버튼이 클릭되었습니다.");
});
```

여기서 화살표 함수는 클릭이 실제로 발생하는 시점에 호출될 콜백입니다. "지금 실행해줘"가 아니라 "나중에 이 일이 생기면 실행해줘"라고 예약해두는 셈입니다.

## 고차 함수란

고차 함수는 함수를 인자로 받거나, 함수를 결과로 반환하는 함수를 말합니다. `addEventListener`도 콜백을 인자로 받으니 고차 함수의 한 예입니다. 직접 만들어보면 더 명확합니다.

```js
function repeat(n, task) {
  for (let i = 0; i < n; i++) {
    task(i);
  }
}

repeat(3, (i) => console.log(`${i}번째 실행`));
```

`repeat`은 반복 횟수와 함께 "매번 무엇을 할지"를 콜백으로 받아, 반복이라는 뼈대와 실제 작업 내용을 분리합니다.

## 왜 유용할까

고차 함수와 콜백을 쓰면 코드의 뼈대(언제, 몇 번 실행할지)와 실제 동작(무엇을 할지)을 분리할 수 있습니다. 그 결과 비슷한 반복 로직을 매번 새로 짜지 않고 재사용할 수 있고, 원하는 동작만 콜백으로 바꿔 끼우면 되니 코드가 훨씬 유연해집니다.
