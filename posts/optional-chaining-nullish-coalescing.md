# 옵셔널 체이닝과 널 병합 연산자

자바스크립트로 객체의 깊은 속성에 접근하다 보면 중간에 `undefined`나 `null`을 만나 에러가 나는 경우가 흔합니다. ES2020에 추가된 두 연산자로 이 문제를 훨씬 간결하게 다룰 수 있습니다.

## 옵셔널 체이닝 (?.)

기존에는 중첩된 속성에 안전하게 접근하려면 이렇게 써야 했습니다.

```js
const city = user && user.address && user.address.city;
```

`?.`을 쓰면 훨씬 짧아집니다.

```js
const city = user?.address?.city;
```

중간 값이 `null`이나 `undefined`이면 에러를 던지는 대신 그 자리에서 바로 `undefined`를 반환합니다. 함수 호출에도 쓸 수 있습니다: `user.greet?.()`는 `greet`이 존재할 때만 호출합니다.

## 널 병합 연산자 (??)

`||`는 `0`이나 빈 문자열처럼 falsy한 값도 모두 걸러버려서 종종 의도치 않은 결과를 만듭니다.

```js
const count = 0;
console.log(count || 10); // 10 (의도와 다름)
console.log(count ?? 10); // 0 (의도한 대로)
```

`??`는 왼쪽 값이 `null` 또는 `undefined`일 때만 오른쪽 값을 사용합니다. 값이 0이나 빈 문자열이어도 그대로 유지하고 싶을 때 `||` 대신 `??`를 쓰면 됩니다.

## 함께 쓰면 좋은 이유

두 연산자를 조합하면 "있으면 쓰고, 없으면 기본값" 패턴을 한 줄로 표현할 수 있습니다.

```js
const displayName = user?.profile?.name ?? "이름 없음";
```

깊은 속성 접근과 기본값 지정을 동시에 안전하게 처리할 수 있어 코드가 훨씬 읽기 쉬워집니다.
