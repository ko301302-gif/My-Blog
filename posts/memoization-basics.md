# 메모이제이션(Memoization)으로 반복 계산 줄이기

같은 입력으로 같은 함수를 여러 번 호출하면 매번 똑같은 계산을 반복하게 됩니다. 메모이제이션은 한 번 계산한 결과를 저장해두고, 같은 입력이 들어오면 저장된 값을 바로 꺼내 쓰는 최적화 기법입니다.

## 왜 필요할까

피보나치 수열처럼 재귀 호출이 많은 함수는 같은 값을 수없이 다시 계산합니다. 입력값이 커질수록 중복 계산이 기하급수적으로 늘어나기 때문에, 계산 결과를 캐싱해두면 속도를 크게 끌어올릴 수 있습니다.

## 간단한 구현

객체나 Map을 캐시로 써서, 함수를 호출하기 전에 이미 계산한 값이 있는지 먼저 확인하면 됩니다.

```js
function memoize(fn) {
  const cache = new Map();
  return function (n) {
    if (cache.has(n)) return cache.get(n);
    const result = fn(n);
    cache.set(n, result);
    return result;
  };
}

const fib = memoize((n) => (n <= 1 ? n : fib(n - 1) + fib(n - 2)));
```

이렇게 하면 이미 계산된 n에 대해서는 함수 본문을 다시 실행하지 않고 캐시에서 값을 바로 돌려줍니다.

## 주의할 점

메모이제이션은 "같은 입력이면 항상 같은 결과"가 보장되는 순수 함수에만 적용해야 합니다. 또한 캐시가 계속 쌓이면 메모리를 많이 차지할 수 있으므로, 입력 종류가 한정적이거나 캐시 크기를 제한할 수 있는 상황에서 쓰는 것이 안전합니다.
