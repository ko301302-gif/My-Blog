# 매직 넘버(Magic Number), 숫자에 이름을 붙여주세요

코드를 읽다가 `if (status === 3)`이나 `setTimeout(fn, 86400000)` 같은 줄을 만나면 저 숫자가 무슨 의미인지 한참 생각하게 됩니다. 이렇게 맥락 없이 코드 안에 박혀 있는 숫자를 매직 넘버라고 부릅니다. 당장은 동작하지만, 시간이 지나거나 다른 사람이 코드를 보면 의미를 알기 어려운 함정이 됩니다.

## 매직 넘버가 문제인 이유

숫자 자체는 아무 설명도 해주지 않습니다. `3`이 "완료 상태"를 뜻하는지, "재고 3개"를 뜻하는지는 코드를 쓴 사람만 알 수 있습니다. 같은 숫자가 여러 곳에 흩어져 있다면, 값이 바뀔 때 전부 찾아서 고쳐야 하고 하나라도 빠뜨리면 버그로 이어집니다.

```js
if (status === 3) {
  // ...
}
```

## 이름 있는 상수로 바꾸기

이럴 때는 의미를 드러내는 상수로 바꿔주면 됩니다. 숫자 하나에 이름을 붙이는 것만으로 코드가 스스로 설명을 하게 됩니다.

```js
const ORDER_STATUS_COMPLETED = 3;

if (status === ORDER_STATUS_COMPLETED) {
  // ...
}
```

시간 값처럼 계산이 들어가는 숫자는 단위를 쪼개 써주면 더 읽기 쉬워집니다.

```js
const ONE_DAY_MS = 24 * 60 * 60 * 1000;
setTimeout(fn, ONE_DAY_MS);
```

## 모든 숫자를 상수로 만들어야 할까요

0이나 1처럼 문맥만으로 의미가 분명한 숫자까지 상수로 빼내면 오히려 코드가 번잡해집니다. 반복해서 등장하거나, 의미를 짐작하기 어렵거나, 나중에 바뀔 가능성이 있는 숫자만 상수로 정리하는 정도로 충분합니다. 핵심은 "이 숫자가 왜 이 값인지" 코드만 보고 알 수 있게 만드는 것입니다.
