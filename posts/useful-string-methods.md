# 자주 쓰는 문자열 메서드로 깔끔하게 다루기

문자열을 다루다 보면 공백을 지우거나, 특정 글자가 들어있는지 확인하거나, 자릿수를 맞춰야 할 때가 많습니다. 자바스크립트는 이런 작업을 위한 메서드를 기본으로 제공하는데, 직접 반복문으로 구현하기 전에 이미 있는 메서드를 아는 것만으로도 코드가 훨씬 짧고 명확해집니다.

## 공백 제거: trim, trimStart, trimEnd

사용자가 입력한 값에는 앞뒤로 불필요한 공백이 섞이기 쉽습니다. `trim()`은 문자열 양쪽의 공백을 모두 지워주고, 한쪽만 지우고 싶다면 `trimStart()`나 `trimEnd()`를 씁니다.

```js
const input = "  hello  ";
input.trim(); // "hello"
input.trimStart(); // "hello  "
```

## 포함 여부 확인: includes

예전에는 `indexOf(str) !== -1`로 포함 여부를 확인했지만, `includes()`를 쓰면 의도가 더 분명하게 드러납니다.

```js
"JavaScript".includes("Script"); // true
```

대소문자를 구분하므로, 구분 없이 비교하려면 둘 다 `toLowerCase()`로 맞춘 뒤 비교해야 합니다.

## 길이 맞추기: padStart, padEnd

자릿수를 맞춰야 할 때는 `padStart()`와 `padEnd()`가 유용합니다. 첫 번째 인자는 목표 길이, 두 번째 인자는 채울 문자입니다.

```js
"7".padStart(2, "0"); // "07"
"5".padEnd(4, "0"); // "5000"
```

시, 분을 두 자리로 맞추는 시계 표시나 주문번호 포맷팅처럼 자릿수가 고정된 값을 다룰 때 자주 쓰입니다.

이렇게 trim, includes, padStart/padEnd만 잘 활용해도 문자열 처리 코드에서 반복문과 조건문을 꽤 많이 줄일 수 있습니다.
