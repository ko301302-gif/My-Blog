# 다크모드에 대한 짧은 생각

다크모드는 이제 선택이 아니라 기본이 되었습니다. 이 사이트는 두 가지 방식을 함께 지원합니다.

1. **시스템 설정 자동 감지** — 별도로 설정하지 않으면 운영체제/브라우저의 `prefers-color-scheme` 값을 따릅니다.
2. **수동 전환** — 헤더의 토글 버튼으로 언제든 바꿀 수 있고, 선택한 값은 `localStorage`에 저장되어 다음 방문에도 유지됩니다.

## 왜 둘 다 필요할까

시스템 설정만 따르면 사용자가 "이 사이트만은 라이트로 보고 싶다"는 선택을 할 수 없고, 수동 전환만 있으면 매번 직접 눌러야 합니다. 두 가지를 함께 지원하면 대부분의 경우 손댈 필요 없이 바로 편한 상태로 보이면서도, 원할 때는 자유롭게 바꿀 수 있습니다.

색상은 CSS 변수로 관리해서, 라이트/다크 테마를 하나의 값 집합만 바꿔서 전환할 수 있도록 만들었습니다.
