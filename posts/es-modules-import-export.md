# ES 모듈(import/export)로 코드 나누기

예전에는 자바스크립트 파일을 여러 개로 나누면 전역 스코프가 뒤섞여서 변수 이름이 겹치는 문제가 흔했습니다. ES6부터 등장한 모듈 시스템은 파일마다 독립된 스코프를 만들어주고, 필요한 값만 명시적으로 내보내고 가져올 수 있게 해줍니다. 빌드 도구 없이도 브라우저에서 `<script type="module">`만 붙이면 바로 쓸 수 있습니다.

## export로 내보내기

함수나 변수 앞에 `export`를 붙이면 다른 파일에서 가져다 쓸 수 있습니다.

```js
// math.js
export function add(a, b) {
  return a + b;
}

export const PI = 3.14;
```

파일당 하나의 대표 값만 내보낼 때는 `export default`를 씁니다.

## import로 가져오기

내보낸 값은 파일 경로와 함께 `import`로 불러옵니다.

```js
import { add, PI } from "./math.js";

console.log(add(1, 2)); // 3
```

경로 앞의 `./`를 빠뜨리면 브라우저가 파일을 찾지 못하니 주의하세요.

## 모듈의 특징

모듈 스코프는 파일마다 독립적이라 같은 이름의 변수가 있어도 충돌하지 않고, 코드는 기본적으로 strict mode로 실행됩니다. 덕분에 파일을 역할별로 나눠도 전역 변수가 오염될 걱정 없이 안전하게 코드를 조직할 수 있습니다.
