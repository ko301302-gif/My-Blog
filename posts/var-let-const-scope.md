# var, let, const의 스코프 차이 이해하기

자바스크립트에서 변수를 선언하는 방법은 var, let, const 세 가지입니다. 셋 다 값을 담는 건 같지만, 어디까지 유효한지(스코프)와 다시 바꿀 수 있는지가 다릅니다. 이 차이를 모르면 생각지 못한 버그를 만나기 쉽습니다.

## 함수 스코프 vs 블록 스코프

var는 함수 스코프를 가져서 if문이나 for문의 중괄호 `{}`를 무시하고 바깥에서도 접근할 수 있습니다. 반면 let과 const는 블록 스코프를 가져서 선언된 `{}` 안에서만 유효합니다.

```js
if (true) {
  var a = 1;
  let b = 2;
}
console.log(a); // 1
console.log(b); // ReferenceError
```

## 재선언과 재할당

var는 같은 이름으로 여러 번 선언해도 에러가 나지 않아 실수로 변수를 덮어쓰기 쉽습니다. let은 재선언은 막지만 값은 바꿀 수 있고, const는 재선언도 재할당도 둘 다 막습니다. 단, const로 선언한 객체나 배열의 내부 속성은 여전히 바꿀 수 있다는 점에 주의하세요.

```js
const user = { name: "Kim" };
user.name = "Lee"; // 가능
user = {}; // TypeError
```

## 언제 무엇을 쓸까

값이 바뀌지 않는다면 const를 기본으로 쓰고, 재할당이 필요한 경우에만 let을 사용하세요. var는 예상치 못한 스코프 문제를 일으킬 수 있어 요즘 코드에서는 거의 쓰지 않습니다.
