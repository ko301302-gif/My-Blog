# 배열 메서드 map, filter, reduce 이해하기

자바스크립트로 배열을 다루다 보면 `for`문 대신 `map`, `filter`, `reduce`를 쓰는 코드를 자주 보게 됩니다. 세 메서드 모두 원본 배열은 그대로 두고 새로운 결과를 만들어낸다는 공통점이 있지만, 하는 일은 각각 다릅니다. 하나씩 살펴보겠습니다.

## map: 각 요소를 변환하기

`map`은 배열의 모든 요소에 같은 함수를 적용해서, 변환된 값들로 이루어진 새 배열을 반환합니다. 배열의 길이는 변하지 않습니다.

```js
const prices = [1000, 2000, 3000];
const withTax = prices.map((price) => price * 1.1);
// [1100, 2200, 3300]
```

## filter: 조건에 맞는 요소만 남기기

`filter`는 조건 함수가 `true`를 반환하는 요소만 모아서 새 배열을 만듭니다. 결과 배열의 길이는 원본보다 같거나 작습니다.

```js
const numbers = [1, 2, 3, 4, 5, 6];
const evens = numbers.filter((n) => n % 2 === 0);
// [2, 4, 6]
```

## reduce: 하나의 값으로 압축하기

`reduce`는 배열의 요소들을 순회하면서 누적값을 계산해 최종적으로 하나의 값으로 만듭니다. 합계, 평균, 객체 변환 등 다양한 곳에 쓰입니다.

```js
const cart = [1000, 2000, 3000];
const total = cart.reduce((sum, price) => sum + price, 0);
// 6000
```

## 세 메서드를 함께 쓰기

실무에서는 이 셋을 이어 붙여 쓰는 경우가 많습니다. 예를 들어 "짝수만 골라서 두 배로 만든 뒤 합산하기"는 `filter`로 거르고, `map`으로 변환하고, `reduce`로 합치는 순서로 표현할 수 있습니다. 처음에는 `for`문보다 낯설 수 있지만, 각 단계가 하는 일이 명확히 나뉘어 있어서 코드를 읽을 때 의도를 파악하기 쉬워진다는 장점이 있습니다.
