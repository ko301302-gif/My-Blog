# 배열 slice와 splice, 헷갈리는 이름 구분하기

자바스크립트 배열에는 이름이 비슷해서 헷갈리기 쉬운 두 메서드가 있습니다. `slice`와 `splice`입니다. 글자 하나 차이지만 동작은 완전히 다릅니다. 하나는 원본 배열을 건드리지 않고, 다른 하나는 원본 배열을 직접 바꿔버립니다. 이 차이를 모르고 쓰면 의도치 않게 원본 데이터가 변경되는 버그를 만들 수 있습니다.

## slice: 원본은 그대로, 일부만 잘라오기

`slice(start, end)`는 배열의 일부를 복사해서 새 배열로 반환합니다. 원본 배열은 전혀 바뀌지 않습니다.

```js
const fruits = ['사과', '바나나', '포도', '딸기'];
const picked = fruits.slice(1, 3);

console.log(picked); // ['바나나', '포도']
console.log(fruits);  // ['사과', '바나나', '포도', '딸기'] (그대로)
```

`end`는 포함되지 않는 인덱스라는 점도 기억해두면 좋습니다.

## splice: 원본을 직접 수정하기

`splice(start, deleteCount, ...items)`는 원본 배열에서 원하는 위치의 요소를 직접 삭제하거나 새 요소를 끼워 넣습니다. 반환값은 삭제된 요소들로 이루어진 배열입니다.

```js
const fruits = ['사과', '바나나', '포도', '딸기'];
const removed = fruits.splice(1, 1, '수박', '참외');

console.log(removed); // ['바나나']
console.log(fruits);  // ['사과', '수박', '참외', '포도', '딸기']
```

## 헷갈리지 않으려면

"slice는 안전하다(복사만 한다), splice는 쓴다(원본을 고친다)"라고 기억하면 구분하기 쉽습니다. 원본을 보존해야 하는 상황이라면 slice를, 배열 자체를 편집하고 싶다면 splice를 쓰면 됩니다.
