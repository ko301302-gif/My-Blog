# 정규표현식(RegExp), 문자열 패턴 찾아내기

이메일 형식이 맞는지 확인하거나, 문자열에서 숫자만 뽑아내야 할 때마다 `if`문과 반복문을 겹겹이 쓰면 코드가 금방 복잡해집니다. 이런 "문자열 패턴 찾기" 작업을 간결하게 처리해주는 도구가 정규표현식입니다. 처음 보면 암호처럼 보이지만, 기본 문법 몇 가지만 알아도 실무에서 꽤 자주 써먹을 수 있습니다.

## 정규표현식 만들기

자바스크립트에서는 슬래시(`/`)로 패턴을 감싸거나 `RegExp` 생성자를 씁니다.

```js
const pattern1 = /\d+/; // 숫자 하나 이상
const pattern2 = new RegExp("\\d+");
```

`test()`는 패턴이 문자열에 있는지 불리언으로 알려주고, `match()`는 실제로 매칭된 부분을 찾아줍니다.

```js
/\d+/.test("가격: 1200원"); // true
"가격: 1200원".match(/\d+/)[0]; // "1200"
```

## 자주 쓰는 패턴 기호

`\d`는 숫자, `\w`는 문자/숫자/언더스코어, `\s`는 공백을 의미합니다. `+`는 1개 이상, `*`는 0개 이상, `?`는 0개 또는 1개를 뜻하고, `^`와 `$`는 각각 문자열의 시작과 끝을 가리킵니다. 예를 들어 `/^\d{3}-\d{4}$/`는 "123-4567"처럼 숫자 3개, 하이픈, 숫자 4개로만 이루어진 문자열을 검사합니다.

## replace와 함께 쓰기

패턴을 찾는 것뿐 아니라 바꾸는 것도 가능합니다. 전체를 바꾸려면 `g`(global) 플래그를 붙입니다.

```js
"2026.10.13".replace(/\./g, "-"); // "2026-10-13"
```

처음에는 패턴을 외우기보다 필요할 때마다 찾아 쓰면서 익숙해지는 것으로 충분합니다. 조금씩 손에 익으면 복잡한 문자열 검증 코드를 훨씬 짧게 쓸 수 있습니다.
