# 배열 메서드 find, some, every로 조건 검사하기

배열에서 특정 조건에 맞는 값을 찾거나, 조건을 만족하는지 검사할 때 for문을 직접 돌리지 않아도 됩니다. find, some, every는 각각 "값 하나 찾기", "하나라도 맞는지", "전부 맞는지"를 간결하게 표현해주는 메서드입니다.

## find: 조건에 맞는 첫 번째 값 찾기

find는 배열을 순회하다가 조건을 만족하는 첫 번째 요소를 반환합니다. 조건에 맞는 값이 없으면 undefined를 반환합니다.

```js
const users = [
  { id: 1, name: "민수" },
  { id: 2, name: "지은" },
];

const user = users.find((u) => u.id === 2);
console.log(user); // { id: 2, name: "지은" }
```

filter와 헷갈리기 쉬운데, filter는 조건에 맞는 모든 요소를 배열로 돌려주고, find는 가장 먼저 찾은 값 하나만 돌려준다는 차이가 있습니다.

## some: 하나라도 조건을 만족하는가

some은 배열 요소 중 단 하나라도 조건을 만족하면 true를 반환합니다. 조건에 맞는 값을 찾는 순간 바로 멈추기 때문에 전체를 다 돌지 않아도 됩니다.

```js
const hasAdult = users.some((u) => u.age >= 20);
```

"재고 중에 품절된 상품이 하나라도 있는가?" 같은 질문에 딱 맞는 메서드입니다.

## every: 모두 조건을 만족하는가

every는 반대로 배열의 모든 요소가 조건을 만족해야 true를 반환합니다. 하나라도 조건에 맞지 않으면 즉시 false로 멈춥니다.

```js
const allAdults = users.every((u) => u.age >= 20);
```

## 정리

find, some, every는 모두 조건 함수를 인자로 받고, 조건에 맞는 값을 찾으면 더 이상 순회하지 않고 바로 결과를 반환합니다. 반복문을 직접 쓰는 것보다 코드가 짧아지고, 이름 자체가 의도를 드러내기 때문에 가독성도 좋아집니다.
