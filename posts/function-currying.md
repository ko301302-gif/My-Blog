# 커링(Currying), 함수를 하나씩 쪼개서 쓰기

여러 개의 인자를 한꺼번에 받는 함수를, 인자를 하나씩만 받는 함수들의 연속으로 바꾸는 기법을 커링이라고 합니다. 모든 값을 한 번에 넘기지 않고, 필요한 값을 하나씩 채워가며 함수를 완성해 나가는 방식입니다.

## 왜 쓸까

커링을 쓰면 자주 쓰는 인자를 미리 고정해둔 함수를 쉽게 만들 수 있습니다. 예를 들어 할인율을 계산하는 함수가 있다면, 할인율은 고정하고 가격만 다르게 넣는 함수를 따로 만들어 재사용할 수 있습니다.

## 간단한 예제

화살표 함수를 중첩해서 쓰면 커링을 쉽게 구현할 수 있습니다.

```js
const discount = (rate) => (price) => price - price * rate;

const tenPercentOff = discount(0.1);
console.log(tenPercentOff(10000)); // 9000
console.log(tenPercentOff(5000));  // 4500
```

`discount(0.1)`을 호출하면 `rate`가 0.1로 고정된 새 함수가 반환되고, 이 함수에 `price`만 넘기면 계산이 끝납니다.

## 언제 유용할까

같은 설정값을 여러 번 재사용하는 함수나, 콜백으로 넘길 함수를 미리 일부만 채워서 전달하고 싶을 때 커링이 유용합니다. 다만 인자가 하나뿐인 간단한 함수까지 억지로 커링할 필요는 없습니다. 필요한 곳에서만 골라 쓰면 코드가 더 깔끔해집니다.
