# 이벤트 루프(Event Loop), 자바스크립트가 비동기를 처리하는 방법

자바스크립트는 한 번에 한 가지 코드만 실행할 수 있는 싱글 스레드 언어입니다. 그런데 `setTimeout`이나 서버에 데이터를 요청하는 작업처럼 시간이 걸리는 일을 어떻게 화면이 멈추지 않고 처리할 수 있을까요? 그 답이 바로 '이벤트 루프'입니다.

## 콜 스택, 코드가 실행되는 곳

```js
function a() { b(); }
function b() { console.log('hi'); }
a();
```

함수가 호출되면 콜 스택에 쌓이고, 실행이 끝나면 스택에서 빠집니다. 콜 스택이 비어 있어야 다음 작업을 실행할 수 있는데, 오래 걸리는 작업을 콜 스택에서 직접 처리하면 그동안 다른 코드는 아무것도 실행되지 못합니다.

## setTimeout은 어디서 기다릴까

```js
console.log('시작');
setTimeout(() => console.log('타이머'), 0);
console.log('끝');
// 시작 -> 끝 -> 타이머
```

`setTimeout`으로 등록한 함수는 콜 스택이 아니라 브라우저(또는 Node.js)가 별도로 관리하는 공간에서 대기하다가, 지정한 시간이 지나면 '태스크 큐'라는 대기열에 들어갑니다. 이벤트 루프는 콜 스택이 완전히 빌 때마다 태스크 큐를 확인해서, 대기 중인 작업을 하나씩 콜 스택으로 옮겨 실행합니다. 그래서 `0`초로 설정해도 항상 동기 코드보다 나중에 실행됩니다.

## 정리

이벤트 루프 덕분에 자바스크립트는 하나의 스레드로도 여러 비동기 작업을 순서대로, 그리고 막힘없이 처리할 수 있습니다. "지금 실행 중인 코드가 먼저 끝나야 대기 중인 콜백이 실행된다"는 원칙만 기억해도 비동기 코드의 실행 순서를 예측하는 데 큰 도움이 됩니다.
