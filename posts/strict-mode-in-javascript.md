# strict mode(엄격 모드)란 무엇일까

자바스크립트는 원래 조금 느슨한 언어입니다. 선언하지 않은 변수에 값을 넣어도 에러 없이 넘어가는 등, 실수를 저질러도 조용히 넘어가는 경우가 많습니다. strict mode는 이런 느슨한 동작을 막고 더 엄격한 규칙으로 코드를 실행하게 해주는 모드입니다.

## strict mode 켜는 방법

파일이나 함수 맨 위에 문자열 `"use strict";`를 적으면 그 범위 전체에 strict mode가 적용됩니다. 참고로 ES6 모듈(`type="module"`)과 클래스 문법은 별도 선언 없이도 기본적으로 strict mode로 동작합니다.

```js
"use strict";

x = 10; // ReferenceError: x is not defined
```

## strict mode가 막아주는 실수들

대표적으로 선언하지 않은 변수 생성을 막고, 일반 함수 안에서 `this`가 자동으로 전역 객체를 가리키는 것도 막아 `undefined`로 남겨둡니다. 또한 같은 이름의 매개변수를 중복 선언하거나, 읽기 전용 속성에 값을 할당하는 등의 코드도 조용히 무시하지 않고 바로 에러를 던집니다.

```js
function sayThis() {
  console.log(this);
}
sayThis(); // 일반 모드: 전역 객체, strict 모드: undefined
```

## 왜 써야 할까

strict mode는 버그를 미리 걸러주는 안전장치 역할을 합니다. 오타로 생긴 전역 변수나 의도치 않은 `this` 참조 같은 문제를 실행 초반에 에러로 알려주기 때문에, 디버깅 시간을 크게 줄여줍니다. 요즘은 모듈과 클래스를 쓰면 자동으로 적용되므로, 특별히 신경 쓰지 않아도 혜택을 보는 경우가 많습니다.
