# 템플릿 리터럴, 문자열을 더 편하게 다루는 방법

자바스크립트에서 문자열을 합칠 때 `+` 연산자를 계속 이어 쓰다 보면 코드가 지저분해지기 쉽습니다. ES6부터 등장한 템플릿 리터럴을 쓰면 훨씬 깔끔하게 문자열을 만들 수 있습니다. 백틱(`` ` ``)으로 문자열을 감싸는 것이 핵심입니다.

## 변수를 문자열에 바로 끼워 넣기

`${}` 안에 변수나 표현식을 넣으면 그 값이 문자열에 그대로 들어갑니다.

```js
const name = "지민";
const age = 27;

// 기존 방식
const greeting1 = "안녕하세요, " + name + "님. 나이는 " + age + "살이네요.";

// 템플릿 리터럴
const greeting2 = `안녕하세요, ${name}님. 나이는 ${age}살이네요.`;
```

`${}` 안에는 단순 변수뿐 아니라 `${age + 1}`처럼 연산식이나 함수 호출도 넣을 수 있습니다.

## 여러 줄 문자열도 그대로

기존에는 여러 줄 문자열을 만들려면 `\n`을 직접 넣어야 했지만, 템플릿 리터럴은 줄바꿈을 입력한 그대로 유지해 줍니다.

```js
const message = `첫째 줄입니다.
둘째 줄입니다.`;
```

HTML 조각을 만들 때처럼 줄바꿈이 잦은 문자열을 다룰 때 특히 유용합니다.

## 정리

템플릿 리터럴은 문자열 연결을 간결하게 만들어 주고, 여러 줄 문자열도 자연스럽게 표현할 수 있게 해 줍니다. 문자열 안에 변수 값을 넣어야 하는 상황이라면 `+` 대신 백틱과 `${}`를 먼저 떠올려 보세요.
