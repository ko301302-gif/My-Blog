# 클로저(Closure), 어렵지 않게 이해하기

자바스크립트를 공부하다 보면 언젠가 "클로저"라는 단어를 마주치게 됩니다. 이름은 낯설지만 개념은 생각보다 단순합니다. 클로저는 함수가 자신이 만들어질 때의 주변 환경(변수)을 기억해서, 나중에 실행될 때도 그 변수에 접근할 수 있게 해주는 특징을 말합니다.

## 간단한 예제로 보기

말로만 설명하면 헷갈리니 코드로 살펴보겠습니다.

```js
function makeCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

`makeCounter` 함수는 실행이 끝나면 사라질 것 같지만, 내부에서 반환한 함수가 `count` 변수를 계속 기억하고 있습니다. 이렇게 함수가 자신이 태어난 스코프의 변수를 붙잡고 있는 현상이 바로 클로저입니다.

## 왜 유용할까?

클로저를 쓰면 변수를 외부에서 직접 건드리지 못하게 숨기면서도, 정해진 함수를 통해서만 값을 바꿀 수 있게 만들 수 있습니다. 위 예제에서 `count`는 외부 코드가 직접 접근할 수 없고, 오직 `counter()`를 호출해야만 값이 바뀝니다. 이런 방식을 활용하면 상태를 안전하게 캡슐화한 함수, 혹은 설정값을 미리 넣어두는 함수 팩토리를 만들 수 있습니다.

## 자주 만나는 실수

반복문 안에서 클로저를 만들 때 `var`를 쓰면 모든 함수가 같은 변수를 공유해서 예상과 다른 값이 찍히는 경우가 있습니다. 이때는 블록 스코프를 갖는 `let`으로 바꾸면 반복마다 독립된 변수가 생겨 문제가 해결됩니다. 클로저는 처음엔 낯설어도, 함수와 스코프의 관계를 이해하는 좋은 출발점이 되어줄 것입니다.
