# 배열 정렬, sort()를 제대로 쓰는 법

자바스크립트 배열에는 `sort()` 메서드가 기본으로 있어서 편하게 정렬할 수 있을 것 같지만, 아무 생각 없이 썼다가는 숫자 배열에서 이상한 결과를 보기 쉽습니다. `sort()`의 동작 방식을 제대로 알아야 원하는 순서로 정렬할 수 있습니다.

## 기본 동작은 "문자열 비교"

`sort()`를 비교 함수 없이 호출하면 배열의 각 요소를 문자열로 바꿔서 비교합니다. 그래서 숫자 배열을 정렬해도 사람이 기대하는 크기 순서가 아니라 문자 순서로 정렬될 수 있습니다.

```js
const numbers = [10, 1, 21, 2];
numbers.sort();
console.log(numbers); // [1, 10, 2, 21]
```

"10"이 "2"보다 먼저 오는 이유는 문자 '1'이 '2'보다 앞서기 때문입니다. 숫자를 크기대로 정렬하려는 의도와는 다른 결과입니다.

## 비교 함수로 원하는 기준 정하기

이 문제를 해결하려면 `sort()`에 비교 함수를 직접 넘겨야 합니다. 비교 함수는 두 값 `a`, `b`를 받아서, 음수면 `a`를 앞에, 양수면 `b`를 앞에, 0이면 순서를 유지합니다.

```js
const numbers = [10, 1, 21, 2];
numbers.sort((a, b) => a - b); // 오름차순
console.log(numbers); // [1, 2, 10, 21]

numbers.sort((a, b) => b - a); // 내림차순
console.log(numbers); // [21, 10, 2, 1]
```

객체 배열을 특정 속성 기준으로 정렬할 때도 같은 방식을 씁니다.

```js
const users = [{ age: 30 }, { age: 20 }, { age: 25 }];
users.sort((a, b) => a.age - b.age);
```

## 원본 배열을 바꾼다는 점 주의하기

`sort()`는 새 배열을 반환하는 게 아니라 원본 배열을 직접 변경(mutate)합니다. 원본을 그대로 유지하고 싶다면 스프레드 연산자나 `slice()`로 복사본을 만든 뒤 정렬하는 것이 안전합니다.

```js
const original = [3, 1, 2];
const sorted = [...original].sort((a, b) => a - b);
console.log(original); // [3, 1, 2] 그대로 유지됨
console.log(sorted);   // [1, 2, 3]
```
