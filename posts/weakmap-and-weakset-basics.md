# WeakMap과 WeakSet, 메모리 누수 걱정 없는 저장소

Map과 Set은 편리하지만, 키나 값으로 객체를 넣어두면 그 객체를 더 이상 쓰지 않아도 가비지 컬렉터가 수거하지 못합니다. WeakMap과 WeakSet은 이런 상황을 위해 만들어진, 키를 "약하게" 참조하는 자료구조입니다.

## 일반 Map과 다른 점

Map은 키로 넣은 객체를 강하게 참조하기 때문에, 다른 곳에서 그 객체를 가리키는 변수를 모두 지워도 Map 안에 남아있는 한 메모리에서 사라지지 않습니다. 반면 WeakMap은 키를 약하게 참조해서, 바깥에서 더 이상 그 객체를 참조하지 않으면 가비지 컬렉터가 자동으로 수거해 갑니다.

## 사용법과 제약

```js
const cache = new WeakMap();
const obj = {};
cache.set(obj, "계산 결과");
console.log(cache.get(obj));
```

WeakMap과 WeakSet은 객체만 키(또는 값)로 쓸 수 있고, 숫자나 문자열 같은 원시값은 넣을 수 없습니다. 또한 size 속성이나 forEach, for...of 같은 반복 기능을 지원하지 않아서, 안에 무엇이 들어있는지 직접 들여다볼 수 없습니다.

## 언제 쓰면 좋을까

DOM 노드마다 추가 데이터를 붙이거나, 특정 객체에 대한 캐시를 만들 때처럼 "이 객체가 살아있는 동안만 데이터를 들고 있고, 객체가 사라지면 데이터도 같이 정리되길 원하는" 상황에 적합합니다. 객체가 언제 사라질지 신경 쓰지 않고도 메모리 누수를 걱정하지 않을 수 있다는 게 가장 큰 장점입니다.
