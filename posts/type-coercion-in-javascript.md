# 암묵적 형변환, 왜 "1" + 1은 "11"이 될까

자바스크립트는 타입이 다른 값끼리 연산을 해도 에러를 내지 않고 알아서 타입을 맞춰버립니다. 이걸 암묵적 형변환(implicit coercion)이라고 부릅니다. 편리해 보이지만 원리를 모르면 예상치 못한 버그의 원인이 되기 쉽습니다.

## + 연산자는 왜 다르게 동작할까

`+` 연산자는 피연산자 중 하나라도 문자열이면 나머지도 문자열로 바꿔 이어붙입니다.

```js
console.log("1" + 1);   // "11"
console.log(1 + "1");   // "11"
console.log(1 + 2);     // 3
```

반면 `-`, `*`, `/`는 문자열을 숫자로 바꾼 뒤 계산합니다.

```js
console.log("5" - 2);   // 3
console.log("5" * "2"); // 10
```

같은 연산자라도 `+`만 예외적으로 문자열 결합을 먼저 고려한다는 점을 기억해 두면 헷갈릴 일이 줄어듭니다.

## 조건문에서의 형변환

`if` 문이나 `while` 문은 조건식을 불리언으로 바꿔서 평가합니다. 이때 `0`, `""`, `null`, `undefined`, `NaN`은 모두 false로 취급되고, 나머지는 true로 취급됩니다.

```js
if ("0") {
  console.log("실행됨"); // 문자열 "0"은 true
}
if (0) {
  console.log("실행 안 됨"); // 숫자 0은 false
}
```

## 헷갈림을 줄이는 방법

암묵적 형변환에 의존하기보다는 `Number()`, `String()`, `Boolean()` 같은 명시적 변환 함수를 사용하고, 비교할 땐 `==` 대신 `===`를 쓰는 습관을 들이면 의도치 않은 동작을 크게 줄일 수 있습니다.
