# Map과 Set, 객체와 배열만으론 아쉬울 때

자바스크립트에서 데이터를 묶어 다룰 때 보통 객체와 배열을 씁니다. 하지만 "키를 문자열이 아닌 값으로 쓰고 싶다"거나 "중복 없는 값 목록을 관리하고 싶다"는 상황이 되면 객체와 배열만으로는 불편해집니다. 이럴 때 쓰는 것이 `Map`과 `Set`입니다.

## Map: 어떤 값이든 키로 쓸 수 있는 객체

객체의 키는 사실 내부적으로 문자열(또는 심볼)로 변환됩니다. 반면 `Map`은 객체, 함수, 숫자 등 어떤 값이든 키로 쓸 수 있습니다.

```js
const userRoles = new Map();
const user1 = { name: "지민" };

userRoles.set(user1, "admin");
console.log(userRoles.get(user1)); // "admin"
console.log(userRoles.size); // 1
```

객체 자체를 키로 쓸 수 있으니, "이 객체에 어떤 값을 연결해둘까" 같은 상황에 잘 맞습니다. 또한 `Map`은 순회 순서가 항상 삽입 순서로 보장된다는 장점도 있습니다.

## Set: 중복을 자동으로 걸러주는 값의 모음

`Set`은 배열과 비슷하지만 같은 값을 두 번 넣을 수 없습니다. 배열에서 중복을 제거하고 싶을 때 흔히 이렇게 씁니다.

```js
const numbers = [1, 2, 2, 3, 3, 3];
const unique = [...new Set(numbers)];
console.log(unique); // [1, 2, 3]
```

`new Set(numbers)`로 배열을 넣으면 중복된 값이 자동으로 걸러지고, 다시 `[...]`로 펼쳐서 배열로 돌려놓는 패턴입니다.

## 언제 쓰면 좋을까

키가 단순 문자열이고 JSON으로 직렬화해야 한다면 여전히 객체가 편합니다. 하지만 키가 객체이거나 삽입 순서·크기 확인이 중요하다면 `Map`을, 중복 제거나 "이 값이 존재하는가"를 자주 확인해야 한다면 `Set`을 선택하는 것이 코드를 더 명확하게 만들어 줍니다.
