# 매개변수 기본값(Default Parameters), 빈 값 걱정 덜어내기

함수를 호출할 때 인자를 빼먹으면 어떻게 될까요? 자바스크립트에서는 전달하지 않은 매개변수가 `undefined`가 됩니다. 매번 `if`문으로 빈 값을 확인하고 기본값을 채워주는 코드를 짜다 보면 번거롭고 지저분해지기 쉽습니다. ES6부터는 매개변수 자체에 기본값을 지정할 수 있어서 이런 반복 코드를 줄일 수 있습니다.

## 기본 문법

매개변수 뒤에 `= 값`을 붙이면, 호출 시 인자가 없거나 `undefined`일 때 그 값이 대신 쓰입니다.

```js
function greet(name = "손님") {
  console.log(`안녕하세요, ${name}님!`);
}

greet("민수"); // 안녕하세요, 민수님!
greet();       // 안녕하세요, 손님님!
```

기존에는 `name = name || "손님"` 같은 코드를 함수 본문 첫 줄에 써야 했지만, 이제는 선언부에서 바로 처리됩니다.

## undefined와 다른 falsy 값의 차이

기본값은 인자가 `undefined`일 때만 적용됩니다. `0`이나 `""`, `null`처럼 다른 falsy 값을 넘기면 기본값이 쓰이지 않고 그 값 그대로 들어갑니다.

```js
function setVolume(level = 50) {
  console.log(level);
}

setVolume(0);    // 0 (기본값 적용 안 됨)
setVolume();     // 50 (기본값 적용)
```

`||`를 쓴 예전 방식은 `0`도 falsy라서 의도와 다르게 기본값으로 바뀌는 버그가 생기기 쉬운데, 기본 매개변수는 이 문제를 깔끔하게 피해갑니다.

## 앞의 매개변수를 참조하기

기본값에는 앞서 선언된 다른 매개변수도 사용할 수 있습니다.

```js
function createUser(name, role = name === "admin" ? "관리자" : "일반") {
  console.log(`${name} - ${role}`);
}

createUser("admin"); // admin - 관리자
```

이렇게 매개변수 기본값을 활용하면 호출부 코드는 간단해지고, 함수 내부에서 값을 검증하고 채워주는 로직도 줄어들어 가독성이 좋아집니다.
