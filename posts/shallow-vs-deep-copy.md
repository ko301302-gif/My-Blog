# 얕은 복사와 깊은 복사, 헷갈리지 않게 정리하기

자바스크립트에서 객체나 배열을 복사했는데, 복사본을 수정했더니 원본까지 같이 바뀌는 경험을 해본 적이 있을 겁니다. 이는 얕은 복사와 깊은 복사의 차이를 모르고 지나칠 때 자주 생기는 버그입니다.

## 얕은 복사란?

얕은 복사는 객체의 최상위 속성만 새로 복사하고, 그 안에 중첩된 객체나 배열은 원본과 같은 참조를 공유하는 방식입니다. 스프레드 문법이나 `Object.assign`이 대표적입니다.

```js
const user = { name: "지민", address: { city: "서울" } };
const copy = { ...user };

copy.address.city = "부산";
console.log(user.address.city); // "부산" — 원본도 바뀜
```

`name`처럼 단순 값은 안전하게 복사되지만, `address`처럼 객체인 속성은 여전히 같은 메모리를 가리키기 때문에 이런 일이 생깁니다.

## 깊은 복사란?

깊은 복사는 중첩된 객체까지 모두 새로운 메모리에 복사해서, 복사본을 아무리 수정해도 원본이 전혀 영향받지 않도록 만드는 방식입니다. 대표적으로 `structuredClone` 함수를 사용할 수 있습니다.

```js
const copy2 = structuredClone(user);
copy2.address.city = "제주";
console.log(user.address.city); // "부산" — 원본은 그대로
```

## 언제 깊은 복사가 필요한가

폼 데이터를 임시로 수정 중이거나, 상태 관리 라이브러리에서 원본 상태를 건드리지 않고 복사본만 바꿔야 할 때 깊은 복사가 필요합니다. 반대로 중첩 구조가 없는 단순한 객체라면 얕은 복사만으로도 충분합니다. 상황에 맞는 복사 방식을 고르는 것이 버그를 줄이는 첫걸음입니다.
